# Mike West

I'm a product builder and author in Pittsburgh, Pennsylvania. I build software, data references and practical guides through [Bicycle LLC](https://bicycle.llc).

I helped build people analytics at Google, Merck and PetSmart, have consulted independently since 2012 for more than 25 companies, and wrote *People Analytics For Dummies* (Wiley, 2019).

I believe measurement science makes AI more trustworthy, and I filed three provisional patent applications in 2026.
